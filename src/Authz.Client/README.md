# Authz.Client

.NET SDK for [ms-authz](../../README.md). Pull-cached effective-permissions lookup,
`RequirePermissionAttribute`, and a MediatR `PermissionAuthorizationBehavior` that enforces it.

See the repo root [README.md](../../README.md#authzclient-sdk) for full usage — registration,
`IAuthzRequestContextAccessor`, and the security boundary this SDK sits behind.
